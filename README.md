# Calculadora (Java)

Calculadora simples desenvolvida em Java, criada como projeto de estudo para praticar lógica de programação e estruturação de código orientado a objetos.

#  Funcionalidades

- Operações básicas: soma, subtração, multiplicação e divisão
- Interface via terminal (linha de comando)

##  Tecnologias

- Java

## Como executar

1. Clone o repositório:
   
   git clone https://github.com/aliciavazherculano/calculadora.java.App.git
   
2. Entre na pasta do projeto:
   
   cd calculadora.java.App
   
3. Compile o arquivo:
   
   javac Calculadora.java
   
4. Execute:
   
   java Calculadora
